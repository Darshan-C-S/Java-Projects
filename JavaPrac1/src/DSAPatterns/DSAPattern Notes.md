### 1. Prefix Sum :(only Easy problems)
Optimizes range sum queries from O(N) to O(1) by pre-calculating cumulative sums.
### 2. Two Pointers : 
Uses two variables to traverse data structures in different directions (often to solve palindrome or search problems). 
3. Sliding Window : Reduces complexity from O(N*K) to O(N) for subarray/substring problems by maintaining a dynamic window. 
4. Fast and Slow Pointers : Useful for detecting cycles or finding the middle element in linked lists. 
5. Linked List In-Place Reversal : A technique to reverse nodes using three pointers (previous, current, next) without extra space. 
6. Monotonic Stack : Keeps elements in a specific order (increasing/decreasing) to find the next greater or smaller element. 
7. Top K Elements : Uses heaps to find the k largest or smallest elements efficiently. 
8. Overlapping Intervals : Involves sorting and merging ranges; useful for scheduling problems. 
9. Modified Binary Search : Adapts standard binary search for rotated arrays or finding bounds. 
10. Binary Tree Traversal : Covers pre-order, in-order, post-order, and level-order techniques. 
11. Depth First Search (DFS) : Explores branches in graphs or trees using recursion or a stack. 
12. Breadth First Search (BFS) : Explores nodes level-by-level using a queue; ideal for shortest path problems. 
13. Matrix Traversal (10:10): Treats 2D grids as graphs, often utilizing DFS or BFS. 
14. Backtracking : Systematically explores potential solution paths and retreats when a path fails. 
15. Dynamic Programming (DP) : Breaks optimization problems into smaller overlapping sub-problems to avoid redundant calculations.
